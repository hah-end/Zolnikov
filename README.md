## 🌐 Получение API-ключа

1. Перейдите на [exchangerate-api.com](https://www.exchangerate-api.com)
2. Нажмите **"Get Free API Key"**
3. Введите ваш email и подтвердите регистрацию
4. Скопируйте полученный ключ (формат: `xxxxxxxxxxxxxxxxxxxxxxxx`)
